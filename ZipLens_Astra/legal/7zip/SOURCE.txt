7-Zip 26.03 — source and redistribution information

ZipLens runs the official 7zz executable as a separate process.
Packaging adds a local ad-hoc code signature for macOS bundle integrity.
No 7-Zip source or executable program code is changed. Signing changes the
executable file bytes; the input hashes below identify the official download.
The signed executable hash is recorded in docs/build-result.json of the project.
7-Zip code is not linked into ZipLens. 7zz and the source archive below are
distributed with their original license notices and without warranty.
