# 변경 이력

## 2.0.0 — 2026-09-06 (렌즈 UI 보완: 2026-09-08)

- 사용자 요청에 따라 이번 개선판의 이름을 **ZipLens 2.0**, 버전을 **2.0.0**으로 확정. 창 제목·메뉴·정보 화면·배포 앱 이름을 통일.

- 렌즈의 광학 특성을 UI에 통합: 오목렌즈/압축 해제는 확산, 볼록렌즈/압축은 수렴. SVG 광선 이동·실제 진행률·동작 줄이기 지원.
- 영어 상태 문자열에 의존하던 애니메이션 선택을 명시적인 작업 종류로 변경해 한국어 등 모든 언어에서 동작. 첫 화면·압축 설정·작업 화면에 같은 시각 체계 적용.
- 압축·압축 해제 완료 화면을 `showArchiveReport()`로 통일. 성공 시 압축은 정지한 볼록렌즈, 해제는 정지한 오목렌즈를 표시하며 취소·일부 실패의 경고 아이콘과 보고서는 유지.
- 완료 시 진행 타이머와 작업 화면을 멈추고, 대화상자를 닫을 때까지 시작 작업 대기열을 보류. 암호 입력창 정리 후 보고서를 열고 배경 화면의 `inert` 및 보고서의 `aria-hidden` 상태를 동기화.
- 압축 결과에는 Finder에서 보기·닫기를 제공하고, 해제 결과에는 조건에 맞는 파일 열기와 기존 상세 목록·TXT/CSV 내보내기를 유지. 완료 대화상자는 애니메이션·블러 없는 고정 배경으로 표시. 실제 압축·일반/암호 ZIP 해제와 상세 보기 후 Escape 닫기를 검증.
- 소개글은 한국어 원문을 유지하며 다른 언어를 선택하면 해당 번역을 문단별로 함께 표시. 영어·일본어·중국어·프랑스어·스페인어·아랍어 지원. 개인 헌사는 번역하지 않고 마지막에 한 번만 유지.
- 알아서 풀기의 달러 기호를 폴더+반짝임 아이콘으로 교체해 자동 압축 해제 의미를 표현.
- 알아서 풀기 버튼의 번역 연결 누락 수정. 지원하는 7개 언어로 즉시 갱신하며 기존 SVG 아이콘과 활성/비활성 상태를 유지.
- macOS 앱 및 웹뷰 favicon에는 기존 렌즈 그림 유지. 렌즈 상태/미정 진행률/중앙 광선 회귀 검사 4개 추가.
- 원본을 보존한 독립 폴더와 앱 식별자 도입.
- 검증한 임시 추출 결과만 파일별로 반영하여 폴더 전체 삭제를 제거.
- 경로 탈출, 외부 링크, 대소문자/유니코드 충돌 검사.
- ZIP 중앙 목록을 재사용하는 병렬 추출로 다수 파일 처리 개선.
- 암호 재입력, 분할 ZIP, 실제 결과 경로, gzip trailer 오류 처리 수정.
- 압축 입력 누락/자기 포함/동일 출력 경로 차단, 기본 레벨 6과 1/9 선택.
- 파일 권한과 시간 처리 개선, 파일/폴더 선택 및 TAR.ZST 옵션 추가.
- 작업 취소와 blocking 작업 분리, 진행 이벤트 빈도 제한.
- UTF-8 선택 목록과 공식 7-Zip 26.03, 취약한 sevenz-rust 의존성 제거, tar 업데이트.
- 목록 HTML 삽입 및 CSV 수식 삽입 방지, CSP 적용.
- 검색, 페이지 이동, 언어 저장, 복합 확장자, 시작 이벤트 handshake 개선.
- 메모리 미리보기 20 MiB 한도와 임시 파일 수명 관리.
- 검토 보고서·개발자 노트·작업 기록·자동 회귀 테스트·재현 가능한 성능 시험 추가.
