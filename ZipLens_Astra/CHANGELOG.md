## 2.1.1 — 2026-10-11 · 공개 프리뷰

- 공개 2.0.3 이후의 앱 이름 정리, 열 가지 언어, 정보창·오프라인 사용법·공식 후원, AI/CLI 기능을 하나의 2.1.1 프리뷰로 배포. 2.1.0은 별도로 공개하지 않음.
- 메인 화면의 파일·폴더 선택과 드래그 입력을 정리. 압축 파일은 미리보기를 열고 일반 파일·폴더·혼합 선택은 선택 항목을 유지한 압축 설정으로 연결. 대상 확인과 다시 선택 추가.
- 메인 렌즈 그림에서 열 가지 렌즈·빛 패턴의 개념도와 설명을 둘러보는 기능 추가. 더블클릭, Enter·Space 키와 처음 화면 복귀 지원.
- ZIP 해제 작업을 압축·해제 크기에 따라 분배하고 전용 작업자 수를 최대 8개로 제한. ZIP 지원 확인과 미리보기 항목 검색 중 취소 확인 보완. 모든 입력에서 속도가 개선된다는 의미는 아님.
- ZipLens 자체 코드에 GNU GPL version 3 only (`GPL-3.0-only`) 적용. 라이선스 전문, 앱 내 고지, 패키지 메타데이터와 배포 검사 반영. 외부 구성요소 라이선스는 유지.
- 공식 앱의 Buy Me a Coffee·Ko-fi·Bitcoin 후원란 유지. README에 수정본 배포 시 원작과 원작자 후원 링크를 남겨 달라는 자발적 협조 요청 추가. 후원과 링크 보존 요청은 추가 라이선스 조건이 아님.
- Apple Silicon 앱 `ZipLens_2.1.1_arm64-preview.zip`과 해당 버전의 대응 소스 `ZipLens_2.1.1_source.tar.gz`를 함께 제공하는 배포 구성. Developer ID 서명·Apple 공증 미완료인 ad-hoc 서명 프리뷰.
- 대응 소스에 배포본의 전체 자체 소스, 실행·빌드 Rust crate 소스와 npm 의존성의 상위 프로젝트 TypeScript 소스 아카이브 포함. 공개 검증 요약과 별도로 개인 작업 기록·원시 로그를 비공개 보관.
- [2.1.1 한국어·영어 업데이트 안내](docs/RELEASE_2.1.1_KO_EN.md)와 [사용 설명서](docs/USER_GUIDE_KO_EN.md) 추가. 다운로드·설치, 실제 GUI 흐름, CLI, 소스·후원 안내 정리.
- 2026-10-10 실전 검사: DNG 728개·HEIC 1개, 총 729개·26.58GB를 ZIP 다섯 묶음으로 압축·복원해 파일명·크기·SHA-256 일치 확인. 네 묶음은 4GiB 초과 ZIP64. 15개·494.7MB 표본의 7Z·TAR·TAR.GZ·TAR.ZST 왕복 및 암호·선택 해제·중복 파일 보존 검사 통과. 같은 날 프런트엔드 56개와 앱 CLI 18개 통과. GUI 전체와 모든 형식·변종을 검사했다는 뜻은 아님. [검증 범위](docs/VALIDATION.md)

## 2.1.1 개발 기록 — 2026-10-08 · 당시 로컬 프리뷰

- 앱 이름을 `ZipLens`, 앱 번들을 `ZipLens.app`으로 통일. 창·메뉴·정보창 제목에서 이름에 붙은 `2.0`을 제거하고 정보창의 실제 앱 버전은 한 번만 표시.
- 사람과 AI가 기본적인 디지털 도구를 지식 공유처럼 자유롭게 사용하며 공존할 수 있기를 바라는 제작 철학으로 소개글 갱신. 무료 사용과 광고 없는 운영, 선택적인 후원의 취지를 한국어·영어·일본어·중국어(간체)·베트남어·스페인어·프랑스어·독일어·러시아어·아랍어에 반영.
- 정보창에 [Buy Me a Coffee](https://buymeacoffee.com/master_chief), [Ko-fi](https://ko-fi.com/seederpower), Bitcoin(BTC) 후원을 함께 안내. BlueWallet에서 받은 일반 Bitcoin 수신 주소 `BC1QUEUAX3FJP77NZUKF732AEWVFE0YVS9ZPKUMLTV`의 복사와 QR 코드를 제공.
- 정보창에서 여는 오프라인 사용법 추가. 같은 10개 언어로 앱 사용과 AI/CLI 이용 방법 안내. 앱에 포함된 문서이므로 기본 사용법을 인터넷 연결 없이 확인 가능.
- 2.1.0의 AI/CLI 인터페이스·10개 언어·Dock 아이콘·기존 압축 엔진 개선을 유지. 이 개발 기록 작성 당시 공개 GitHub 릴리스는 2.0.3이었으며 변경은 로컬 프리뷰에만 반영.

## 2.1.0 — 로컬 개발 기록, 별도 공개 릴리스 없음

- 베트남어·독일어·러시아어를 추가해 요청 순서의 10개 언어 지원. 압축 설정·진행·파일 선택 제목·오류 안내·보고서·정보창·후원·기본 앱 설정과 사용자 정의 macOS 메뉴를 현지화. 저장된 언어 및 시스템 선호 언어를 검증해 선택하고, 지원하지 않는 경우 영어로 표시.
- Dock 아이콘의 흰 바깥 배경을 투명하게 처리하고 렌즈 그림의 폭을 캔버스 약 93%로 확대. 투명 PNG 원본, 데스크톱 아이콘과 favicon을 갱신. 2026-10-07 자동 검사 137개, macOS 빌드·패키징과 설치본 대조, 실제 미리보기·한글 검색·선택 해제 확인. [점검 범위와 제한](docs/VALIDATION.md#210-dock-아이콘과-기능-점검--2026-10-07).
- 같은 앱 실행 파일에 창 없이 동작하는 `cli capabilities`, `list`, `extract`, `compress` 추가. AI와 터미널 자동화에 JSON 결과·오류 코드·종료 코드를 제공.
- 목적지를 명시하고, 기존 파일은 기본적으로 다른 이름으로 보존. 명시적인 `--overwrite`에서만 덮어쓰기. 실제 결과 경로와 일부 실패를 보고.
- 기존 엔진의 경로·원본 보호·CRC 검증을 재사용하고, 정확한 항목 이름 선택과 표준 입력 암호 전달 지원.
- 기존 Finder 실행과 GUI 명령 동작 유지. [AI/CLI 계약](docs/AI_CLI.md)과 실제 실행 파일을 사용하는 회귀 검사 추가.
