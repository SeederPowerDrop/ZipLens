# 검증 기록

## 2.0.1 다운로드·시작 오류 수정 — 2026-09-13

- 사용자 다운로드 ZIP의 SHA-256이 GitHub 배포본과 일치. CRC, macOS `ditto` 재추출 및 추출 앱의 strict/deep 서명 검증 통과. 기존 Rust ZIP 엔진으로도 270개 파일 추출 및 실행 권한·서명 보존 확인.
- 기존 `/Applications/ZipLens 2.0.app`을 종료한 뒤 Finder에서 샘플 ZIP 더블클릭 시 시작 중 `SIGABRT` 종료 재현. 수정한 2.0.1은 같은 초기 파일 열기 경로에서 8개 파일 목록을 정상 표시했고 앱 정보의 2.0.1 표시 확인.
- 프런트엔드 13개, Tauri 라이브러리 8개(초기 Finder 요청 회귀 포함), 패키징 19개 검사 통과. GitHub 재게시 전 압축 엔진 전체 61개를 추가 실행해 총 101개 검사 통과.
- TypeScript/Vite 빌드, 최적화 macOS 앱 빌드, Tauri Clippy·서식 검사 통과. Google Drive의 부모 파일 읽기 시간 초과를 피해 동일 소스를 로컬 임시 폴더로 복사해 빌드.
- `--preview` 실물 패키징 성공: `release_build/preview/ZipLens_2.0.1_arm64-preview.zip`. 실제 압축 해제 후 파일·권한·서명 검사 통과, 체크섬 자동 생성. SHA-256: `47dc1b2f0f18456b4f1fff0f850423dc3322a7810340228da0472c89af217f97`.
- 공개 패키징은 자격 증명이 없으면 기존 결과물 변경 전에 중단함을 확인. 공개 결과물 생성 후 프리뷰 생성 시 공개 앱·체크섬·검증 기록을 보존하는 회귀 검사 포함.
- 정식 Apple 공증은 사용 가능한 Developer ID 인증서가 없어 실행하지 않음. 공증 승인·거부 및 Gatekeeper 거부 처리는 모의 서비스로 검사했고, 기존 2.0.0 실물 앱의 Gatekeeper 결과는 `rejected`. 프리뷰의 실행 검증을 공증 완료로 취급하지 않음.
- 루트 README와 앱 README의 스크린샷 2개는 실제 앱 화면을 촬영해 육안 확인. 공개용 샘플 ZIP을 사용.

상세 원인과 사용 안내: [macOS 다운로드 앱 실행 문제](MACOS_LAUNCH_KO.md).

환경: Apple M3 / 메모리 24 GiB / macOS 15.7.5. 날짜: 2026-09-05~06.

전체 158개 파일 대조는 앞서 모두 일치했습니다. 마지막 전체 재검사는 Google Drive의 원본 7-Zip 매뉴얼 파일 읽기에서 지연되어 제한 시간 내 끝나지 않았습니다. 원본 소스 코드는 별도로 다시 검사해 변경 없음을 확인했으며 `original-verification.json`에 구분해 기록했습니다.

## 실제 UI 확인

컴퓨터 화면 도구로 최적화 빌드를 실행해 다음 흐름을 확인했습니다.

1. 앱 이름·한국어 초기 화면·중복 없는 툴바 라벨.
2. 생성한 테스트용 ZIP(652개 엔트리) 파일 선택 및 목록 표시.
3. `<img src=x onerror=alert(1)>.txt`가 HTML 실행 없이 글자로 표시됨.
4. `한글` 검색으로 결과 1개 표시.
5. `한글 안내.txt` 더블클릭으로 실제 텍스트 내용 표시.
6. 전체 선택 해제 후 한 파일만 선택해 알아서 풀기. 성공 보고서와 디스크 파일 내용을 대조함.
7. 압축 레벨·파일/폴더 선택·분할·암호 체크 시 입력창과 AES 선택 표시.

이것은 모든 버튼·모든 언어·모든 Finder 이벤트를 자동으로 검사하는 GUI 테스트 모음은 아닙니다. 초기 화면 도구 지연과 파일 선택창 조작 오류 후 재시도하여 위 흐름을 확인했습니다.
