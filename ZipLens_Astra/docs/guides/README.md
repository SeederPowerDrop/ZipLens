These seven guides cover the 2.1.3 introduction, features, DMG installation, everyday use and validation limits. **Help / User guide** opens the selected language's guide on GitHub `main` in a browser. Internet access is required; online docs may be updated after an app release. If the browser cannot launch, the bundled basic guide is shown. A network failure inside an opened browser does not automatically show that fallback.
