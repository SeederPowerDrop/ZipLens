**先查看压缩包，再提取需要的文件。** ZipLens 是 SeederPowerDrop 开发的免费、无广告 macOS 应用，以透镜聚光和散光的形象表现压缩与解压。

## 主要功能

- 浏览文件夹、搜索名称、选择条目，预览支持的小型图片和 UTF-8 文本。
- 创建 **ZIP、7Z、TAR、TAR.GZ、TAR.ZST**。图形界面支持 ZIP/7Z 密码和分卷选项；ALZ/EGG 仅支持解压。
- 处理重名、取消任务，并在结果报告中查看实际输出路径和错误。
- 十种界面语言、GitHub 使用指南，以及同一应用的 [JSON CLI](../AI_CLI.md) 自动化接口，无须额外的 AI API 密钥。

## 使用 DMG 安装

1. 完成当前任务，用 **⌘Q** 退出旧版本，然后打开 DMG。
2. 将**完整的 ZipLens.app 复制到“应用程序”**。替换已有安装前先备份。
3. 启动复制后的应用，在 **ⓘ** 中核对 **2.1.3**，然后推出 DMG 卷。

这是 **Apple Silicon 的 ad-hoc 签名预览版，尚未通过 Apple 公证**。DMG 不能代替公证，macOS 仍可能阻止启动。无法保证在所有其他 Mac 上运行，也未验证 Intel Mac。如果信任应用来源，请按照 [Apple 官方说明](https://support.apple.com/102445)自行决定是否手动允许运行。 [DMG、下载与安装的实际验证](../INSTALLATION_VALIDATION_2.1.3_KO_EN.md)。

## 基本操作

1. **解压：** 拖入或打开压缩包，浏览并勾选条目，再选择解压和目标文件夹。需要时输入密码。
2. **压缩：** 拖入或选择文件、文件夹，设置格式、选项、名称和保存位置。建议先使用平衡设置；已经压缩的照片、视频可能几乎不会变小。
3. **检查结果：** 核对实际输出路径和错误。取消或失败后，已完成的文件可能保留。分卷压缩包需将所有分卷放在一起，并打开第一卷。

在窗口上方切换语言。**ⓘ → 使用指南 / 帮助**会在浏览器中打开对应语言的 GitHub `main` 文档，需要联网。无法启动浏览器时会显示内置基础指南；浏览器打开后的网络错误不会自动触发该备用指南。**ⓘ** 中还有许可证、可选捐助、Bitcoin 地址和二维码。

## 既有性能测量：2.1.2 引擎

下列数据来自 **2026 年 10 月 18 日的 2.1.2 CLI/引擎测试**，并非 2.1.3 重新测试。环境为 Apple M3、24 GiB 内存、macOS 15.7.5，压缩级别 6。

| 数据 | 观察结果 |
|---|---|
| 单个 4 GiB + 64 MiB 文件，约 4.36 GB | 2.1.2 ZIP 压缩中位数 64.9 秒，解压 8.5 秒；各测两次 |
| 10,000 个 4 KiB 文件，每版本追加六次 | 解压中位数：**2.1.1 的 0.722 秒 → 2.1.2 的 0.815 秒** |
| 512 MiB 混合样本，7Z 压缩 | 每 100ms 采样的进程树 RSS 最高值约 **1.71 GiB** |

**40 次完整往返包括 2.1.1 的 14 次和 2.1.2 的 26 次**，文件名、大小和 SHA-256 均一致，原始文件得到保留。小文件解压中位数约增加 12.8%，测量范围重叠，原因尚未确定，因此不宣称全面提速。RSS 采样可能漏掉短暂峰值，或重复计算共享页面。[完整结果与限制](../LARGE_FILE_VALIDATION_2026-10-18.md)

## 使用限制

创建 ZIP 时密码须使用可打印 ASCII；Unicode 密码请选 7Z。界面语言不决定文件名编码。支持 UTF-8 和有效的 Unicode 路径信息；无编码标记的旧 ZIP 采用 CP949 兼容解释，无法总是正确恢复 CP932、GBK、CP437 名称。必要时请提供方重新制作 UTF-8 ZIP 或 7Z。文本预览使用 UTF-8，解压不会改变原始内容的编码。系统对话框遵循 macOS 设置；并未验证所有压缩变体和所有 Mac。[支持范围](../../README.md#지원-범위)
