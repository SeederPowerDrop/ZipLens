# ZipLens 简介、功能与使用指南

[所有语言](README.md) · 更新日期：2026年10月18日

ZipLens 是 SeederPowerDrop 开发的免费、无广告 macOS 压缩工具。你可以先查看压缩包内容，再只提取需要的文件。界面用聚光透镜表示压缩，用散光透镜表示解压。

## 安装与版本

从 [2.1.2 发布页面](https://github.com/SeederPowerDrop/ZipLens/releases/tag/v2.1.2)下载 `ZipLens_2.1.2_arm64-preview.zip`。完成当前操作，用 ⌘Q 退出旧版，再用 macOS 归档实用工具解压，将完整的 `ZipLens.app` 放入“应用程序”。替换已有安装前先备份，并在 **ⓘ** 中核对版本。

这是 Apple Silicon 预览版，仅使用 ad-hoc 签名，尚未完成 Apple Developer ID 签名和公证，macOS 可能阻止启动。Intel Mac 上的运行尚未验证。可下载的应用仍为 **2.1.2**；`main` 分支可能包含 **Unreleased（尚未发布）**的修复。更新源码或文档不会自动更新已安装的应用。

## 功能说明

- 创建 **ZIP、7Z、TAR、TAR.GZ、TAR.ZST**。图形界面中的 ZIP、7Z 支持密码和分卷。ZIP 默认采用 AES-256；设有密码的 7Z 还会加密文件列表。TAR 仅打包，TAR 系列不提供密码或分卷选项。创建 ZIP 的密码须使用可打印的 ASCII（英文字母、数字、符号）；需要中文等 Unicode 密码时请选择 7Z。
- 浏览目录、按名称搜索、选择性解压、取消任务和查看结果。支持的图片、文本在小于 **20 MiB** 时可在应用内预览；其他文件会临时解压并交给默认应用打开。 文本预览仅按 UTF-8 解码；若旧编码的正文显示乱码，请先提取，再用支持该编码的编辑器打开，这属于显示问题，与解压时保留原始字节是两回事。
- 支持打开并解压 ALZ、EGG 等更多格式，但识别扩展名不代表支持其所有变种。请查看[格式范围](../../README.md#지원-범위)。
- 同一个应用提供 JSON CLI，供自动化工具调用，详见 [CLI 参考](../AI_CLI.md)。CLI 目前没有分卷创建选项。

## 打开与解压

1. 将压缩包拖到窗口，或使用上方的“打开”选择文件。如果只选择了多个压缩包，将打开第一个并显示提示。
2. 浏览文件夹、搜索名称，勾选需要的文件或全选。双击文件可预览或打开。
3. 点击解压操作，选择目标文件夹；需要时输入密码。自动解压会保存在原压缩包旁边；若选中多个顶层项目，会创建以压缩包命名的文件夹。
4. 出现同名冲突时选择处理方式，结束后检查结果中的实际路径与错误。取消或失败后，已完成的文件可能仍然保留。分卷压缩包须将所有分卷放在同一目录，并打开第一卷。

## 创建压缩包

拖入或选择文件、文件夹，设置格式和选项，再压缩选中项目并指定名称与保存位置。压缩包与普通文件混合选择时，也会创建新压缩包。也可以从新建压缩操作开始。

建议先选均衡模式。快速模式优先节省时间，最大压缩模式可能耗时更长。已经压缩的照片或视频可能几乎不会缩小。

## 语言与应用信息

在窗口上方切换语言；阿拉伯语采用从右到左的阅读方向。macOS 自带对话框遵循系统语言，压缩引擎的详细错误可能使用其他语言。默认压缩应用设置改变 Finder 打开文件时使用的应用，不会替换右键菜单的压缩命令。

**ⓘ** 中包含作者、版本、离线指南与自愿支持方式。“开源许可证”按钮会在 Finder 中打开随应用提供的许可证文件夹。Bitcoin 收款地址复制和二维码也在这里。

## 文件名与性能

界面语言和文件名编码是两回事。支持 UTF-8 与有效的 ZIP Unicode 路径信息；缺少标记的旧 ZIP 文件名使用兼容韩语 CP949 的回退解释。没有编码标记的 Shift-JIS/CP932、GBK、CP437 无法始终自动判断。遇到问题可请创建者重新生成 UTF-8 ZIP 或 7Z。切换界面语言不会修复乱码；解压也不会翻译内容或改变文本文件编码。

速度取决于格式、文件数量、压缩级别与存储设备。[验证记录](../VALIDATION.md)说明了测试条件和已知限制，不代表任何压缩包都能完全无错运行。
