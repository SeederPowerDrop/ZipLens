# ZipLens 소개·기능·사용 설명서

[모든 언어](README.md) · 갱신: 2026-10-18

ZipLens는 SeederPowerDrop이 만든 무료·광고 없는 macOS 압축 앱입니다. 압축을 풀기 전에 내용을 확인하고 필요한 파일만 골라 꺼낼 수 있습니다. 빛을 모으는 렌즈는 압축을, 빛을 퍼뜨리는 렌즈는 압축 해제를 나타냅니다.

## 설치와 버전 확인

[2.1.2 릴리스](https://github.com/SeederPowerDrop/ZipLens/releases/tag/v2.1.2)에서 `ZipLens_2.1.2_arm64-preview.zip`을 받습니다. 진행 중인 작업을 마치고 구버전을 ⌘Q로 종료한 뒤 macOS 아카이브 유틸리티로 풉니다. `ZipLens.app` 전체를 응용 프로그램 폴더에 두세요. 기존 설치본을 교체할 때는 먼저 백업하고, **ⓘ**에서 버전을 확인합니다.

Apple Silicon용 ad-hoc 서명 프리뷰이며 Apple Developer ID 서명·공증은 완료하지 않았습니다. macOS가 실행을 차단할 수 있고 Intel Mac 실행은 검증하지 않았습니다. 다운로드 앱은 **2.1.2**이며 `main`에는 **Unreleased(미배포)** 수정이 있을 수 있습니다. 소스·문서 갱신만으로 설치된 앱이 바뀌지는 않습니다.

## 주요 기능

- **ZIP, 7Z, TAR, TAR.GZ, TAR.ZST 생성:** 화면에서 ZIP·7Z 암호와 분할 압축을 설정합니다. ZIP 기본 암호화는 AES-256이며 암호를 지정한 7Z는 파일 목록도 암호화합니다. TAR는 묶기만 하며 TAR 계열은 암호·분할 옵션이 없습니다. ZIP 생성 암호는 영문·숫자·기호 등 출력 가능한 ASCII를 사용하고, 한글 등 다국어 암호는 7Z를 선택하세요.
- **목록·검색·선택 해제·취소·결과 보고서:** 지원하는 이미지·텍스트는 **20 MiB 미만**일 때 앱 안에서 미리 봅니다. 다른 파일은 임시로 풀어 기본 앱에서 엽니다. 텍스트 미리보기는 UTF-8로 해석하므로 구형 인코딩의 본문이 깨져 보이면 추출 후 해당 인코딩을 지원하는 편집기에서 여세요. 이는 압축 해제 시 원본 바이트를 보존하는 것과는 별개의 표시 문제입니다.
- **다양한 형식 열기:** ALZ·EGG는 해제 전용입니다. 확장자를 인식해도 모든 변종을 지원하는 것은 아닙니다. [지원 범위](../../README.md#지원-범위)를 확인하세요.
- **AI·자동화:** 같은 앱의 JSON 명령줄 인터페이스를 사용할 수 있습니다. [CLI 설명서](../AI_CLI.md)를 참고하세요. CLI에는 분할 생성 옵션이 없습니다.

## 파일 열기와 압축 해제

1. 압축 파일을 창에 놓거나 **열기 / 파일 선택**을 누릅니다. 압축 파일만 여러 개 선택하면 첫 파일을 열고 안내합니다.
2. 폴더를 탐색하거나 이름으로 검색하고, 전체 또는 필요한 항목을 체크합니다. 파일을 두 번 클릭하면 미리 보거나 엽니다.
3. **압축 해제**에서 목적지를 고르고 요청 시 암호를 입력합니다. **알아서 풀기**는 원본 옆에 저장하며, 선택한 최상위 항목이 여러 개면 압축 파일 이름의 폴더를 만듭니다.
4. 이름 충돌 안내에서 처리 방법을 선택하고 결과창의 실제 경로와 오류를 확인합니다. 취소·실패 시에도 이미 완료된 파일은 남을 수 있습니다. 분할 압축은 모든 조각을 같은 폴더에 두고 첫 조각을 엽니다.

## 새 압축 만들기

파일·폴더를 놓거나 선택한 뒤 형식·옵션을 정하고 **선택한 항목 압축**에서 이름과 목적지를 지정합니다. 압축 파일과 일반 파일의 혼합 선택도 새 압축을 만듭니다. **새로 압축 → 선택하고 압축**으로 시작해도 됩니다. **균형**으로 시작하세요. **빠르게**는 속도를 우선하며 **최대 압축**은 오래 걸릴 수 있습니다. 이미 압축된 사진·영상은 크기가 거의 줄지 않을 수 있습니다.

## 언어·정보창

창 상단에서 언어를 바꾸며 아랍어는 오른쪽부터 읽습니다. macOS 자체 창은 시스템 언어를 따르고 엔진 오류는 다른 언어일 수 있습니다. **기본 압축 앱 설정**은 Finder의 열기 연결을 바꾸며 우클릭 압축 명령은 바꾸지 않습니다.

**ⓘ**에 제작자·버전·오프라인 사용법·선택적 후원을 모았습니다. **오픈소스 라이선스**는 동봉한 라이선스 폴더를 Finder에서 엽니다. Bitcoin 수신 주소 복사와 QR 코드도 정보창에서 확인합니다.

## 파일명과 성능

화면 언어와 파일명 인코딩은 별개입니다. UTF-8과 유효한 ZIP Unicode 경로 정보를 지원하며, 표시 정보 없는 구형 ZIP은 한국어 CP949 호환 방식으로 해석합니다. 무태그 Shift-JIS/CP932·GBK·CP437 이름까지 항상 추측할 수는 없습니다. 필요하면 제작자에게 UTF-8 ZIP이나 7Z로 다시 만들어 달라고 요청하세요. 화면 언어 변경으로 깨진 이름이 복구되지는 않습니다. 압축 해제는 파일 내용을 번역하거나 텍스트 인코딩을 바꾸지 않습니다.

속도는 형식·파일 수·압축 정도·저장 장치에 따라 달라집니다. 측정 조건과 남은 한계는 [검증 기록](../VALIDATION.md)에 있으며 모든 압축 파일의 무오류를 보장하지는 않습니다.
