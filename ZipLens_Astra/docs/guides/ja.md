# ZipLens の紹介・機能・使い方

[すべての言語](README.md) · 更新日：2026年10月18日

ZipLens は SeederPowerDrop が開発した、無料で広告のない macOS 向けアーカイブアプリです。展開前に中身を確認し、必要なファイルだけ取り出せます。光を集めるレンズで圧縮を、光を広げるレンズで展開を表しています。

## インストールとバージョン

[2.1.3 リリース](https://github.com/SeederPowerDrop/ZipLens/releases/tag/v2.1.3)から `ZipLens_2.1.3_arm64-preview.dmg` をダウンロードします。作業を終えて旧版を ⌘Q で終了し、DMG を開いて、表示された `ZipLens.app` を **Applications** のショートカットへドラッグしてください。既存のアプリを置き換える場合は、先にバックアップします。ディスクイメージを取り出した後、アプリケーションフォルダから ZipLens を起動し、**ⓘ** で **2.1.3** を確認します。

同梱のアプリは Apple Silicon 用の ad-hoc 署名付きプレビューです。Apple Developer ID による署名・公証は未完了のため、macOS が起動を止める場合があります。Intel Mac での動作は未検証です。配布アプリは **2.1.3**、`main` には **Unreleased（未リリース）**の修正が含まれる場合があります。ソースや文書の更新だけではインストール済みアプリは変わりません。

## 主な機能

- **ZIP、7Z、TAR、TAR.GZ、TAR.ZST の作成。** ZIP・7Z は画面からパスワードと分割を設定できます。ZIP の既定の暗号化は AES-256、パスワード付き 7Z はファイル一覧も暗号化します。TAR はファイルをまとめるだけで、TAR 系にはパスワード・分割機能がありません。ZIP 作成時のパスワードは表示可能な ASCII（英数字・記号）を使い、日本語などの Unicode 文字を含む場合は 7Z を選びます。
- フォルダの閲覧、名前検索、選択展開、キャンセル、結果確認。対応する画像・テキストは **20 MiB 未満**ならアプリ内で表示し、ほかのファイルは一時展開後に既定のアプリで開きます。 テキストのプレビューは UTF-8 として表示するため、旧来の文字コードの本文が文字化けする場合は展開後に対応するエディターで開いてください。これは展開時の元データのバイト保持とは別の表示上の問題です。
- ALZ・EGG などの展開にも対応しますが、すべての形式の派生仕様を保証するものではありません。[対応範囲](../../README.md#지원-범위)を参照してください。
- 同じアプリの JSON CLI を自動化に利用できます。[CLI リファレンス](../AI_CLI.md)を参照してください。CLI には分割作成オプションがありません。

## 開く・展開する

1. アーカイブをウィンドウにドロップするか、上部の開く操作で選択します。複数のアーカイブだけを選ぶと、通知とともに最初のファイルが開きます。
2. フォルダを移動・検索し、全項目または必要な項目を選択します。ファイルをダブルクリックすると表示または起動します。
3. 展開操作で保存先を指定し、求められたらパスワードを入力します。自動展開では元のアーカイブの隣に保存し、最上位の選択項目が複数ならアーカイブ名のフォルダを作ります。
4. 同名ファイルがある場合は処理を選び、結果画面で実際の保存先とエラーを確認します。中断・失敗後も完了済みのファイルは残る場合があります。分割アーカイブは全パーツを同じフォルダに置いて最初のパーツを開きます。

## 新しいアーカイブを作る

ファイルやフォルダをドロップ・選択し、形式とオプションを設定して、選択項目の圧縮から名前と保存先を指定します。アーカイブと通常ファイルを混ぜた選択も新規圧縮になります。新規作成ボタンから始めることもできます。まずはバランス設定を使い、時間優先なら高速、サイズ優先なら最大を選んでください。最大設定は時間がかかることがあり、圧縮済みの写真・動画はあまり小さくならない場合があります。

## 言語と情報画面

言語は上部で切り替えます。アラビア語は右から左に表示します。macOS 自体の画面はシステム言語に従い、エンジンの詳細エラーは別言語の場合があります。既定のアーカイブアプリ設定は Finder の開く操作に適用され、右クリックの圧縮操作は変わりません。

**ⓘ** に作者、バージョン、使い方ガイド、任意の支援方法を掲載しています。ホーム画面と **ⓘ** のガイドリンクは、現在の表示言語に対応する GitHub の説明を既定のブラウザーで開きます。ブラウザーを開く処理に失敗した場合は、その旨を知らせて同梱のガイドを表示します。オープンソースライセンスのボタンは同梱のライセンスフォルダを Finder で開きます。Bitcoin の受取アドレスのコピーと QR コードもここにあります。

## ファイル名と速度

画面の言語とファイル名の文字コードは別です。UTF-8 と有効な ZIP Unicode パス情報に対応しますが、情報のない旧式 ZIP には韓国語 CP949 互換の解釈を使います。指定のない Shift-JIS/CP932、GBK、CP437 は必ず判別できるわけではありません。必要に応じて作成者に UTF-8 ZIP または 7Z での作り直しを依頼してください。言語切替では文字化けは修復できず、展開によって内容の翻訳やテキストの文字コード変換は行いません。

速度は形式、ファイル数、圧縮設定、保存装置によって異なります。[検証記録](../VALIDATION.md)の条件と限界を確認してください。あらゆるファイルでの無エラー動作を保証するものではありません。
