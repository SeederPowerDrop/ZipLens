# ZipLens 2.0.0 프리뷰 — ALZ·EGG 해제와 파일 보호 개선

무료 압축 앱 ZipLens 2.0의 첫 프리뷰를 공개합니다. 이번 다운로드는 **Apple Silicon Mac용(arm64)**입니다.

## 이전 GitHub 게시본에서 달라진 점

9월 8일에 게시한 2.0 소스와 비교해 다음 기능을 추가·보완했습니다.

- **ALZ·EGG 해제 추가:** 파일 목록, 필요한 파일만 해제, 내부 파일 미리보기를 지원합니다.
- **파일 인식 8개 → 36개:** 확장자 별칭을 포함한 수치입니다. 압축된 TAR 내부 선택, 단일 압축 스트림과 만화 파일 형식 처리도 보완했습니다.
- **기본 압축 앱 설정:** 앱의 설정에서 원하는 확장자를 연결하면 Finder 더블클릭으로 ZipLens 미리보기가 열립니다. Finder의 우클릭 ‘압축’ 명령은 기존과 같습니다.
- **원본 파일 보호 강화:** 원본·분할 조각의 덮어쓰기와 잘못된 바로가기 생성을 막고, TAR 압축 중 원본 크기가 달라지면 기존 결과를 보존합니다.
- **작업 순서와 취소 개선:** 확인창을 띄운 동안 다른 파일 요청은 기다립니다. 암호 제출 중 취소, 창 닫기 후 상태 복원, 내부 미리보기 종료를 보완했습니다.
- **라이선스 자료 동봉:** 정보 창에서 오픈소스 고지와 7-Zip·일부 구성요소의 대응 소스를 확인할 수 있습니다. 배포 파일의 도구·고지·실행 권한도 검사합니다.

기존 공개 릴리스 1.3.0을 사용하셨다면, 2.0의 렌즈 모양 작업·완료 화면, 검색·페이지 이동, 선택 해제와 다국어 안내도 함께 이용할 수 있습니다.

## 다운로드와 사용

첨부된 **ZipLens_2.0.0_arm64.zip**을 내려받아 풀고 `ZipLens 2.0.app`을 사용할 위치에 둡니다. 기존 ZipLens와 구별되는 앱 이름과 식별자를 사용하므로 나란히 보관할 수 있습니다. 기본 앱으로 사용할 경우 2.0의 설정에서 연결할 형식을 선택하세요.

새 압축 파일 생성은 **ZIP, 7Z, TAR, TAR.GZ, TAR.ZST** 5종이며 ZIP/7Z는 암호·분할 압축을 지원합니다. **ALZ·EGG는 해제 전용**입니다.

## 검증 범위

자동 검사 **87개**가 통과했습니다. 실제 앱에서 한글 ALZ·암호화 EGG 해제, 잘못된 암호·취소·재시도, 내부 미리보기, 창 복원, 충돌창 중 Finder 요청 순서를 확인했습니다.

이번 파일은 **프리뷰이며 Apple Developer ID 서명·공증을 완료하지 않았습니다.** macOS에서 실행 경고나 차단이 발생할 수 있습니다. Intel 실행과 모든 압축 변형의 호환성을 검증한 것은 아닙니다. EGG의 암호화된 파일명·전체 헤더는 지원하지 않으며 AES/LEA 및 일부 AZO 변형은 아직 검증하지 않았습니다.
